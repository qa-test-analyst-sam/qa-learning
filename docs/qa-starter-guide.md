# QA essentials: a starter guide

Welcome to quality assurance. QA is the practice of helping a team deliver software that works for the people who use it. Testing is one important part of that work.

## A practical testing loop

1. **Understand the change.** Read the requirement and ask what a user needs to do.
2. **Explore the risks.** Consider common paths, unusual inputs, permissions, and failure cases.
3. **Choose a test approach.** Use a focused check, a written test case, exploratory testing, or automation as appropriate.
4. **Observe and record.** Compare actual behavior with the expected result. Save useful evidence.
5. **Share findings clearly.** Report reproducible issues with context and impact.
6. **Check the fix.** Retest the issue and consider nearby behavior that could be affected.

## Remember

- Testing can show that defects are present; it cannot prove that none exist.
- Start with the risks that matter most to users.
- Keep test cases readable and maintainable.
- Report observations without blame. A useful bug report helps the team learn.

## Beginner practice

Pick a familiar website. Try creating an account, submitting an empty form, using an invalid email, refreshing a page, and navigating with only a keyboard. Note what you expected, what happened, and how someone else can repeat each observation.
