# Bug report checklist

Use this checklist to make an issue easy to understand and reproduce.

- **Title:** State the observed problem and where it occurs.
- **Environment:** Include browser, operating system, app version, and relevant device details.
- **Preconditions:** Explain the account state or setup needed before starting.
- **Steps to reproduce:** Number each action in order. Keep the steps specific.
- **Expected result:** Describe what should happen.
- **Actual result:** Describe what happened instead.
- **Evidence:** Add a screenshot, recording, console output, or request details when useful.
- **Impact:** Explain which user or workflow is affected and how severely.

Keep reports factual and concise. One issue per report makes triage and verification easier.
